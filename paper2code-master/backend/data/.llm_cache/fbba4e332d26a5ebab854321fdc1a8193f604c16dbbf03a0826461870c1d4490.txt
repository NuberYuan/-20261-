# Rule-Based Graph Programs Matching the Time Complexity of Imperative Algorithms

## 项目简介

本项目实现了论文 **"Rule-Based Graph Programs Matching the Time Complexity of Imperative Algorithms"** 中描述的增强型 GP 2 编译器（Enhanced GP 2 Compiler with Improved Graph Data Structure）。

该编译器基于 GP 2（一种基于规则的图变换语言）的编译框架，通过改进底层图数据结构（如邻接表与邻接矩阵的混合存储、增量式匹配索引等），使得基于规则的图程序在时间复杂度上能够匹配命令式算法（如深度优先搜索、拓扑排序等）的实现。

## 核心模块说明

### `src/src/enhancedgp2compilerwithimprovedgraphdatastructure.py`

该模块实现了增强型 GP 2 编译器，核心改进包括：

- **混合图数据结构**：结合邻接表与邻接矩阵的优点，支持高效的图遍历与边查询。
- **增量式匹配索引**：在规则匹配过程中维护索引结构，减少重复扫描。
- **规则编译优化**：将图变换规则编译为高效的内部表示，降低运行时开销。

### `main.py`

主入口脚本，负责：

- 解析命令行参数
- 加载 YAML 配置文件
- 初始化日志记录器
- 实例化编译器并执行编译流程
- 输出实验结论（基于实际运行结果动态生成）

## 实验说明

本项目通过实际运行编译器，对图程序（如深度优先搜索、拓扑排序等）的编译与执行时间进行测量。实验结论（如时间复杂度的对比）基于实际测量结果动态计算得出，不预设任何先验结论。
