Based on the table analyses, the main experimental findings are as follows. The ablation study indicates that the best overall performance is achieved with a test length of 100, 200 units, a specific discount factor, Watkins Q(λ) enabled, and task penalty enabled, where Copying, 2-row Addition, and Single Digit Multiplication all reach 100% solved; however, Reverse and 3-row Addition remain unsolved across all configurations, and Reverse and Walk improve substantially only when a feedforward controller is used. Vocabulary size experiments show that tasks such as Copying, Reverse, Walk, and Addition exhibit varying vocabulary sizes as the number of symbols increases, while Single Digit Multiplication maintains a small vocabulary size and has an invalid entry at vocabulary size 2. A comparison of reward types reveals that continuous reward generally yields the highest performance, particularly for Walk, Addition, and Single Digit Multiplication, whereas 0/1 and discretized rewards produce similar lower results, suggesting continuous reward provides the most effective learning signal.
