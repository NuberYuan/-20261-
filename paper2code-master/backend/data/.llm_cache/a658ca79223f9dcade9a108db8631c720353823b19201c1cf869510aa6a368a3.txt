# AdaDec: A Uncertainty-Guided Lookahead Decoding Framework for LLM-Based Code Generation

## 项目简介

本项目实现了论文 **"AdaDec: A Uncertainty-Guided Lookahead Decoding Framework for LLM-Based Code Generation"** 的完整实验框架，涵盖数据准备、模型加载、训练、评估与对比分析全流程。

AdaDec 框架的核心思想是利用**不确定性引导的 lookahead 解码策略**，在代码生成任务中通过前瞻性解码与不确定性估计来提升生成代码的质量与可靠性。本仓库提供了多种主流代码大语言模型的接入实现，并支持从零训练（scratch）与迁移学习两种训练模式。

## 环境要求

### 硬件环境

- **GPU**: NVIDIA RTX 5880 Ada Generation (48 GB VRAM) 或 NVIDIA A100 (80 GB VRAM)
- **驱动**: NVIDIA Driver 550.163.01 及以上
- **CUDA**: 12.4

### 软件依赖

- Python >= 3.9
- PyTorch >= 2.1
- 其他依赖见 `requirements.txt`

安装依赖：

```bash
pip install -r requirements.txt
```

## 快速开始

### 1. 配置环境

所有实验配置集中在 `config/config/config.yaml` 中，包括数据路径、模型架构、训练超参数、日志设置等。请根据实际环境修改以下关键项：

- `data.root`: 数据集根目录
- `system.device`: 使用的 GPU 设备（如 `cuda:0`）
- `system.num_workers`: 数据加载线程数
- `training.epochs`: 训练轮数
- `training.batch_size`: 批大小（默认 1，受限于 lookahead 解码的显存占用）

### 2. 运行主程序

```bash
python main.py
```

主程序将依次执行以下流程：

1. 加载配置并初始化日志系统
2. 加载并预处理数据集
3. 根据配置构建模型（支持多种架构）
4. 执行训练（scratch 或迁移学习模式）
5. 在测试集上评估模型
6. 对比不同模型/训练模式的性能

### 3. 评估与对比

训练完成后，评估结果将自动保存至日志目录。如需单独运行评估或对比分析：

```bash
# 评估单个模型
python evaluation/evaluation/evaluate.py --config config/config/config.yaml

# 对比多个模型
python evaluation/evaluation/compare.py --config config/config/config.yaml
```

## 配置说明

### 数据配置 (`data`)

- `data.root`: 数据根目录
- `data.default.path`: 默认数据集路径
- `data.feature_dim`: 特征维度
- `data.normalization`: 是否归一化
- `data.versions`: 可用数据版本列表

### 模型配置 (`model`)

支持以下模型架构：

| 模型 | 参数量 | 文件 |
|------|--------|------|
| DeepSeek-Coder-13B-Instruct | 13B | `deep_seek_coder13_b67_b_instruct.py` |
| Qwen2.5-Coder-1.5B-Instruct | 1.5B | `qwen25_coder15_b7_b_instruct.py` |
| Qwen3-0.6B | 0.6B | `qwen306_b.py` |
| Qwen3-1.7B | 1.7B | `qwen317_b.py` |
| Qwen3-4B | 4B | `qwen34_b.py` |
| Qwen3-8B | 8B | `qwen38_b.py` |
| Stable-Code-Instruct-3B | 3B | `stable_code_instruct3_b.py` |

通过 `model.architectures` 指定使用的模型列表。

### 训练配置 (`training`)

- `training.optimizer`: 优化器配置（名称、学习率、动量、权重衰减）
- `training.scheduler`: 学习率调度器（StepLR，`step_size` 与 `gamma` 见配置文件）
- `training.loss_function`: 损失函数（Binary cross-entropy loss）
- `training.epochs`: 训练轮数（默认 30）
- `training.batch_size`: 批大小（默认 1）
- `training.early_stopping`: 是否启用早停

### 训练模式 (`training_modes`)

- `scratch`: 从零训练（随机初始化权重）
- `pretrained`: 迁移学习（加载预训练权重）

### 日志与检查点 (`logging` / `checkpoint`)

- 日志保存至 `logging.log_dir`
- 检查点保存频率与路径由 `checkpoint` 配置控制

## 复现步骤

### 步骤 1: 数据准备

确保数据集已下载并放置在 `data.root` 指定路径。数据集格式需与 `data/data/dataset.py` 中的 `__getitem__` 实现一致。

### 步骤 2: 修改配置

编辑 `config/config/config.yaml`，设置：

- 数据路径
- 模型架构列表
- 训练超参数
- 训练模式（scratch / pretrained）

### 步骤 3: 运行实验

```bash
python main.py
```

### 步骤 4: 查看结果

训练与评估日志保存在 `logging.log_dir` 目录下，包含：

- 训练损失曲线
- 评估指标（accuracy、precision、recall、F1 等）
- 模型检查点（`.pt` 文件）

### 步骤 5: 模型对比

使用 `evaluation/evaluation/compare.py` 对不同模型或训练模式的结果进行对比分析，对比结果以表格和图表形式输出。

## 评估指标

评估模块（`utils/utils/metrics.py`）实现了以下指标：

- **Accuracy**: 准确率
- **Precision**: 精确率
- **Recall**: 召回率
- **F1-Score**: F1 分数
- **AUC-ROC**: ROC 曲线下面积

## 注意事项

1. **显存管理**: 由于 lookahead 解码策略的显存开销较大，默认 `batch_size=1`。如显存充足（如 A100 80GB），可适当增大批大小。

2. **检查点与验证**: 论文原始实验未设置独立验证集。本框架在训练过程中从训练集二次划分验证集（比例由 `split_strategy.val_split_ratio` 控制），用于模型选择与早停判断。`checkpoint.best_metric` 默认使用验证集准确率（`val_accuracy`），如需严格复现论文设置，可调整相关配置。

3. **结果对比**: 不同模型或训练模式之间的性能对比完全基于实际评估结果动态计算，不预设任何结论性判断。最终报告中的比较结论由实验数据驱动生成。

4. **随机种子**: 通过 `system.seed` 设置全局随机种子，确保实验可复现。`split_strategy.seed` 控制数据划分的随机性。
